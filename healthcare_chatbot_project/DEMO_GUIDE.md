# 🎬 Demo Guide - Healthcare Chatbot

## Quick Demo Script

### 1. **First Impression** (0-10 seconds)
When you first load the page:
- ✨ **Loading screen** appears with animated spinner
- 🎨 **Gradient background** fades in with floating particles
- 📱 **Interface slides in** with staggered animations
- 🤖 **Welcome message** appears from the bot

**What to notice:**
- Smooth, professional loading experience
- Premium dark mode aesthetic
- Glassmorphism effects on cards

---

### 2. **Typing Indicator Demo** (10-30 seconds)

**Try this:**
1. Type "I have a fever" in the input box
2. Press Enter or click Send

**Watch for:**
- 🤖 **Robot icon** appears and bounces
- 💬 **Status text** changes:
  - "Analyzing your query"
  - "Processing information"
  - "Preparing response"
  - "Almost ready"
- ⚫⚫⚫ **Three dots** bounce in sequence with glow
- 📊 **Progress bar** fills from left to right
- ✨ **Shimmer effect** sweeps across the indicator
- 💫 **Pulse animation** on the border
- 🌊 **Float animation** - subtle up/down movement
- 🌟 **Glow effect** radiates from behind

**Duration:** 2-3 seconds (varies by message length)

---

### 3. **Message Interaction** (30-60 seconds)

**Try these actions:**

#### Send Messages
- Type "I have a cough"
- Use quick action buttons (Fever, Cough, Emergency, Help)
- Notice the smooth slide-in animation for each message

#### Copy Messages
- Click any message bubble
- See the checkmark confirmation
- Text is copied to clipboard

#### View Timestamps
- Each message shows the time it was sent
- Hover over messages to see elevation effect

---

### 4. **Quick Actions** (60-90 seconds)

**Click each quick action button:**
- 🌡️ **Fever** - Instant message about fever
- 🫁 **Cough** - Instant message about cough
- ⚠️ **Emergency** - Emergency information
- ❓ **Help** - Help and guidance

**Notice:**
- Ripple effect on button click
- Icon animation on hover
- Smooth message sending

---

### 5. **Language Switching** (90-120 seconds)

**Try this:**
1. Click the **Language** dropdown in navbar
2. Select **Hindi**
3. Send a message in Hindi
4. Switch back to **English**

**What happens:**
- Dropdown has glassmorphism effect
- Smooth transition between languages
- Bot responds in selected language

---

### 6. **Clear Chat** (120-150 seconds)

**Try this:**
1. Click the **Clear** button (trash icon)
2. Confirm the dialog
3. Watch the chat fade out
4. New welcome message appears

**Notice:**
- Confirmation dialog prevents accidents
- Smooth fade-out animation
- Fresh start with welcome message

---

### 7. **Keyboard Shortcuts** (150-180 seconds)

**Try these shortcuts:**
- `Ctrl/Cmd + K` - Focus the input box
- `Ctrl/Cmd + L` - Clear the chat
- `Enter` - Send message
- `Shift + Enter` - New line in message

### 9. **Hover Effects** (210-240 seconds)

### 10. **Accessibility Features** (240-270 seconds)

## 💡 Tips for Best Demo

1. **Start with a clean browser** - No extensions that might interfere
2. **Use a large screen** - Shows all features best
3. **Demonstrate mobile** - Resize to show responsiveness
4. **Highlight typing indicator** - It's the star of the show
5. **Show keyboard shortcuts** - Demonstrates polish
6. **Test accessibility** - Shows professional quality
7. **Emphasize no page reloads** - Pure AJAX experience
